# TaskScheduler

## 📌 Проект

Система управления проектами и задачами на основе микросервисной архитектуры.

Проект предназначен для организации рабочего процесса: пользователи могут создавать проекты и задачи, редактировать их, отслеживать статус выполнения и использовать теги для категоризации.

## ✨ Достижения

- Реализовала **микросервисную архитектуру** с разделением системы на AuthService и NoteService.
- Реализовала **аутентификацию и авторизацию** пользователей с использованием JWT.
- Реализовала механизм **Access и Refresh Token** для управления пользовательскими сессиями.
- Реализовала **хэширование паролей** с использованием BCrypt.
- Реализовала **ролевую модель доступа** с ролями User и Admin.
- Реализовала **управление проектами и задачами**: создание, получение, редактирование и удаление.
- Реализовала **систему статусов задач**: Pending, InProgress и Completed.
- Реализовала **систему тегов** для категоризации проектов и задач.
- Реализовала **асинхронное взаимодействие между микросервисами** через RabbitMQ.
- Реализовала **обработку события регистрации пользователя**: после регистрации через RabbitMQ в NoteService автоматически создаются проект и задача.

## 🌐 Технологический стек

### Backend

- **Платформа**: .NET 8
- **Фреймворк**: ASP.NET Core Web API
- **Архитектура**: микросервисная
- **ORM**: Entity Framework Core
- **API-документация**: Swagger / OpenAPI

### Хранение данных

- **СУБД**: PostgreSQL
- **Доступ к данным**: Entity Framework Core

### Аутентификация и авторизация

- **Аутентификация**: JWT
- **Токены**: Access Token, Refresh Token
- **Хэширование паролей**: BCrypt
- **Роли**: User, Admin

### Взаимодействие между сервисами

- **Брокер сообщений**: RabbitMQ
- **Тип взаимодействия**: синхронное через HTTP API и асинхронное через сообщения

### Валидация и обработка ошибок

- **Валидация**: FluentValidation
- **Обработка результатов**: CSharpFunctionalExtensions
- **Обработка исключений**: Middleware
- **Логирование**: ILogger
